# Sherlock OSINT Assignment

## 1. Tool Name

Sherlock

## 2. Tool Description

Sherlock is an open-source OSINT tool used to search for a username across
many public social networks and websites.

It helps security researchers and investigators determine whether the same
username appears on multiple public platforms.

## 3. Objective

The objective of this assignment is to understand how username enumeration
works using an OSINT tool.

## 4. Environment

- Operating System: Kali Linux
- Tool: Sherlock
- Category: OSINT
- Technique: Username Enumeration

## 5. Installation

Sherlock was installed and executed on Kali Linux.
